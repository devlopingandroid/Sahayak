# SAHAYAK roadmap

These are proposed next steps, not implemented feature claims or promised dates. Current evidence is recorded in [VALIDATION.md](VALIDATION.md).

| Priority | Work | Completion evidence |
|---|---|---|
| 1 | Finish final-device browser voice and a fresh cloud eight-photo enrollment | Record device/browser, conditions, accepted samples and failures. |
| 1 | Measure camera uptime, queue pressure and battery runtime | Publish test duration, frame counts, failures and latency percentiles. |
| 1 | Keep documentation and demo aligned with deployed behavior | Trace demonstrated features to source and dated checks. |
| 2 | Evaluate familiar-person and object recall on consented representative examples | Report false matches, misses and sample selection. |
| 2 | Improve patient/caretaker accessibility and proper-name correction | Structured usability sessions and documented interaction findings. |
| 2 | Strengthen account roles, export/deletion and secret handling | Audited access paths and verified backup/restore and deletion procedures. |
| 2 | Establish sustainable cloud operations | Monitoring, capacity measurements, provider quotas and recovery plan. |
| 3 | Evaluate tagged belongings, OCR and reliable room localization | Separate implementation and evaluation for each extension. |
| 3 | Consider mobile support, physical Help input and life-story albums | Reviewable prototypes with their own usability evidence. |

Single patient/single caretaker operation and one backend replica remain the current scope. Outdoor tracking, always-listening speech, fall detection and medication-ingestion verification have not been established by this project.
